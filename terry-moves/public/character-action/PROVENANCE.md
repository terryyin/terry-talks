[the Three.js RobotExpressive example](https://github.com/mrdoob/three.js/tree/dev/examples/models/gltf/RobotExpressive),
acquired during story preparation on 2026-10-12. The retained bytes are
463,988 bytes with SHA-256:


Model: **Tomás Laulhé (Quaternius)**. Modifications: **Don McCurdy** (facial
expression morph targets, FBX2GLTF conversion and material cleanup).
The source README states **CC0 1.0**; its exact downloaded text is preserved in
[UPSTREAM-README.md](UPSTREAM-README.md). See [the CC0 dedication](https://creativecommons.org/publicdomain/zero/1.0/).

The file contains two skins and named clips including `Idle`, `Walking`, `Wave`
and `ThumbsUp`. There is no turn clip. This saved file, rather than the mutable
upstream `dev` branch, is the reproduction input. Routine previews and renders
read it locally and perform no actor acquisition.
